# 岔路 · Branch Road

> LLM 即时分支叙事游戏 —— 末班地铁，一部不属于你的手机，23:47 发出的一条消息。
> 竖切 0.1（好玩验证版）：8 回合一条完整故事线 + 平行结局回看。

## 玩（本机）

```
py -3 server.py        →  浏览器打开 http://127.0.0.1:8777
```

回车开始。每回合读一段叙事，选一个行动（或直接输入你想做的任何事）。
8 回合后抵达结局；结局后可以按「看看：如果你做了另一个选择」回看平行结局。

依赖：`ZHIPU_API_KEY` 环境变量（glm-4-flash 免费）；`py -3`；浏览器。

## 竖切验证的命题（唯一 KPI）

**"你会不会想知道另一种选法？"**

观测探针（全部进浏览器 console，前缀 `[岔路]`）：
- `beat N`：每回合的选择 + 是否用了自由输入
- `reroll`：换选项的次数（AI 选项不够吸引 = 负信号）
- `ALT-VIEWED`：是否回看了另一条路（**核心正信号**）
- `END`：完整选择路径

## 设计骨架

- **框架固定，分支即生**：末班地铁 / 林晚的手机 / 23:47 的定时草稿 / 终点站。系统提示里埋了渐次暗示的真相线索（广播杂音、车窗倒影多出的轮廓、车轮节奏），叙述者被要求永远不说破。
- **自由输入**是第一公民：选项目录是给犹豫者的，你永远可以直接行动。
- **回看平行结局**是回访钩子：结局不是终点，岔路才是。

## 已知边界（竖切 0.1）

- 单线真相骨架，重玩新鲜度取决于 CogView 场景板的扩展（管线已就绪）
- 无存档续玩、无音效（AudioSynth 管线可接）
- glm-4-flash 文笔偶有翻译腔；BR_MODEL 环境变量可换 glm-4.5-air 等更强模型
